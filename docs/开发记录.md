- **22:44 卡点：域名 HTTPS 被备案拦截**：给 jiawis.cn 加了子域名 outfit.jiawis.cn，certbot 验证拿到 403，返回页标题是 "Non-compliance ICP Filing"——jiawis.cn 没在阿里云备案接入。换 8443 端口 + DNS 验证签了证书，curl 仍在 TLS 握手时被重置：阿里云按 TLS 握手里的域名（SNI）拦截，换端口也没用（OpenSSL 3 能连上，是因为它的握手包更大、被拆成两段，拦截没识别出来，靠这个不可靠）。
