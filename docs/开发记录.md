- **21:58 场景定清楚**：用户是小红书博主。金主（品牌方）可能只给几张衣服图；博主和智能体多轮对话，聊出场景和风格（AI 给建议）→ 先产出脚本 → 最终产出图文笔记；最好还能出视频。
- **22:08 API 实测**：用 qwen-image-3.0-pro 自己生成衣服图和模特图，每张 41–46 秒；用 wan2.7-image-pro 做"多图参考试衣 + 换场景"，一次成功，用时 14 秒，面料、纽扣、口袋都对得上，唯一偏差是衬衫没按要求塞进裤腰（正好用来演示改图）。
- **22:08 卡点：百炼账号开着"仅使用免费额度"**：happyhorse-1.1-i2v 返回 403 AllocationQuota.FreeTierOnly，免费额度已用完。改测 wan2.6-i2v-flash；正式演示前需要在控制台关掉这个开关并充值。
- **22:09 视频实测通过**：wan2.6-i2v-flash，720P、5 秒、自带音轨，52 秒出片；动作按提示词走（看窗外→转头看镜头微笑→整理领口→镜头推近），衣服细节保持住，脸有轻微变化。链路上的三种能力（看图理解→试衣换景→图生视频）都已证明可用。
- **22:12 定架构、派活**：写好 docs/设计.md（场景、架构、接口约定、卡片结构、数据表）；服务端（FastAPI + LangGraph + Postgres + Worker）和 App（Expo）按同一份接口约定拆成两个任务，派给两个 Codex 并行开发，各在自己的 git worktree 里，互不干扰。
- **22:27 App 交付方式**：Gary 想走 TestFlight，最后在 Mac 上镜像 iPhone 演示；开发者账号是 97000945@qq.com，需确认是付费会员。计划用 Expo 云打包（EAS Build）直接传 TestFlight，本机不用装 Xcode。
- **22:28 决定 iOS 交付走免费方案**：用免费 Apple ID + Xcode 直接装到 Gary 的 iPhone（7 天有效），演示时用 iPhone 镜像投到 Mac；不用不确定归属的开发者账号。Gary 开始下载 Xcode。
- **22:28 加一道外部评审**：Gary 要求方案出来后让 Fable（另一个模型）做技术评审、提优化建议。
- **22:31 卡点：qwen-image-3.0-pro 多图改图连不回来**：同样的"模特 + 两件衣服 + 场景"请求，两次都没拿到结果（一次 Node fetch 报 fetch failed，一次 curl 在 61 秒时连接断开，HTTP 000）。它只有同步接口，出图超过约 60 秒就被链路上的超时切断。对比 wan2.7-image-pro 14 秒稳定返回，生成主力定为 wan2.7-image-pro；qwen-image 只用于生成测试素材（文生图 41–46 秒能返回）。
- **22:44 服务器到位**：Gary 提供阿里云杭州 ECS（2 核 3.4G）。先把上面原有的 LobeChat、chatgpt-web、paper-tracker、QuanBot 等服务停掉（只停不删，清单和恢复命令放在服务器 /root/STOPPED-FOR-OUTFIT-20261020.md），空出 2.7G 内存。
- **22:44 卡点：域名 HTTPS 被备案拦截**：给 jiawis.cn 加了子域名 outfit.jiawis.cn，certbot 验证拿到 403，返回页标题是 "Non-compliance ICP Filing"——jiawis.cn 没在阿里云备案接入。换 8443 端口 + DNS 验证签了证书，curl 仍在 TLS 握手时被重置：阿里云按 TLS 握手里的域名（SNI）拦截，换端口也没用（OpenSSL 3 能连上，是因为它的握手包更大、被拆成两段，拦截没识别出来，靠这个不可靠）。
- **22:44 解决**：改用 IP 直连——Let's Encrypt 已支持给 IP 地址签证书（shortlived 档，约 6 天），在服务器上用 lego 走 HTTP-01 签发，cron 每天检查、剩 3 天自动续。服务地址定为 https://47.97.153.127:8443，证书校验通过。
- **22:45 App 验收通过并合入主线**：Codex 交付"衣序"App（对话工作台、六种卡片、改图弹窗、选图排序、笔记预览、视频播放、断网与登录过期处理）+ 本地假服务 + 18 张流程截图。Claude 复测：类型检查、代码检查、26 个单元测试、iOS/Android 打包全部通过。
- **22:51 服务端第一版验收**：Codex 交付 FastAPI + LangGraph（PostgresSaver、interrupt 确认）+ Postgres 任务队列（SKIP LOCKED、租约、去重键）+ Worker。Claude 复测 64 个测试全过、ruff 干净、Mock 端到端通过；Codex 用真实模型跑通一整条（5 图 + 改图 + 视频，约 7 元估算，走免费额度）。
- **22:51 评审发现硬伤**：Fable 评审 + Claude 读代码确认——阶段内的意图识别是关键词表（连"通勤风"都写死了），回复是模板句，模型每次被强制只能调一个指定工具。这是"状态机 + 关键词"，不是智能体，面试官一眼能看穿。决定开第二轮：阶段之间状态机（代码管钱），阶段之内由模型从允许的工具里自己选（ReAct），回复由模型写。
