## 成功标准（Claude 会自己复测，不信自报）

- **A1 登录与隔离**：`/admin` 用 `ADMIN_TOKEN` 登录；不登录或 App 用户的 bearer 访问 `/api/admin/*` 一律 401/403；`ADMIN_TOKEN` 为空时管理端整体关闭（返回 404），不能误开。
- **A2 五个页面都能用**：总览、用量统计（按模型/用户/天，可筛用户，能导出 CSV）、模型与配额、任务队列（失败重试、排队取消真的生效）、用户管理（禁用后该用户登录和写接口 403，启用后恢复；改层级立即生效）。手机宽度（390px）排版不乱。
- **A3 运行时配置真的生效**：在管理端把出图模型换成另一个候选，不重启，Worker 下一次出图用新模型（Mock 模式下用 `/api/health` 或任务记录能看出来）；每日预算到上限时，App 侧花钱动作被拒绝并收到中文提示，对话不受影响；预算未到时一切照旧。
- **A4 数据与迁移**：新表和新字段走 Alembic；空库和现有库（线上有数据）都能迁移；旧账本按项目回填 `user_id`。
