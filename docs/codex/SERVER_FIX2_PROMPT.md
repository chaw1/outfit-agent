# /goal：服务端第三轮——局部改、指令核对、引用图片、忽略吊牌

线上（https://47.97.153.127:8443）真实跑通后，Claude 看了成品图，发现两个问题：

1. **吊牌被穿上身**：衣服原图上的吊牌、织标贴纸被当成衣服的一部分，贴在胸口和裤腰上；还原分质检还拿吊牌文字扣分。
2. **改图没做到**：v2 指令"衬衫塞进裤腰"，结果衬衫还在外面，系统没发现，因为质检只看还原度、不看指令。

同时 Gary 要求手机上的改图交互要像样：能圈出一块（比如袖口）只改那一块、能引用某张图在对话里说事。新约定见 `docs/设计.md` 第 8 节（只增不改），App 正在并行改。

## 成功标准（Claude 会复测，含真实图片目检）

- **T1 局部改**：`edit_image` 支持 `region` 与 `mask_strokes`。做法按第 8.3 节：蒙版 → 外接框扩边裁剪 → 只编辑裁剪块（附原衣服图）→ 羽化贴回。测试证明**蒙版外像素不变**（羽化带以外逐像素一致）；坐标越界、空轨迹、极小区域都有明确中文报错。也可以调研百炼原生的带蒙版编辑能力，用实验对比后选更好的，选型写进 FINAL。真实跑一次"只改袖口"，并附前后对比图。
- **T2 指令核对**：每次改图（整张和局部）完成后，用看图模型对比前后两张图判断指令是否做到，写入 `image.edit_check`；没做到则加强指令自动重试一次（每个改图请求最多重试一次），仍没做到就如实标注，主动播报里说清楚。用真实的"衬衫塞进裤腰"验证：要么做到，要么诚实标注没做到，不能静默。
- **T3 忽略吊牌**：出图提示、改图提示、还原分质检都明确忽略吊牌、价签、织标贴纸、衣架、包装；用带吊牌的衣服图真实生成，成品图上不出现吊牌（目检 + 质检不再因吊牌文字扣分）。
- **T4 引用图片**：`POST /messages` 的 `refs` 进入智能体上下文（被引用图片的镜头、版本、还原分），"这张袖口卷起来了，放下来"在带 ref 时解析到那张图；`message.refs` 能读回。
- **T5 不退步**：全部测试通过（只改适配、不删断言），ruff 干净，Mock e2e 与 `scripts/experiments.py` 通过；e2e 增加局部改和引用两步。
