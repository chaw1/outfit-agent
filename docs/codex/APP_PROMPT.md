# /goal：做出穿搭笔记智能体的手机 App（iOS / Android）

Gary 在面一家做 AI 内容的公司，作业要求 24 小时内交付一个 App demo，面试官会在 Gary 的 iPhone 上看演示、也会逐行看代码。场景、接口、卡片结构都写在 `docs/设计.md`，那是唯一约定；服务端正由另一个人按同一份约定并行开发，**不要私自改接口**，有出入在 FINAL.md 里单列。

用户是小红书穿搭博主。App 要让博主觉得"这是给我用的工具"：新建一个品牌合作项目，上传几张衣服图，在一个对话工作台里和智能体把场景、风格、脚本聊出来，看着图一张张生成，挑图、说一句话改图，最后拿到一篇可以直接发的小红书图文笔记（有条件再加一条短视频）。

## 要求

- **技术**：Expo SDK 58 + expo-router + TypeScript（strict）。必须能在 iPhone 的 **Expo Go** 里直接跑（不用自定义原生模块），同时保留以后 `expo prebuild` / EAS 打包成独立 App 的能力（app.json 里写好 bundleIdentifier / package、图标、启动页）。也要能 `expo start --web` 跑起来，方便截图核对。
- **页面**：
  - 登录 / 注册；
  - 项目列表：品牌、阶段、封面；
  - 新建项目：标题、品牌、需求描述、上传衣服图（多张）、可选上传"我的照片"当模特；
  - **对话工作台**（核心）：消息流 + 按 `card.type` 渲染的卡片（衣服分析、方向选择、脚本、图片网格、笔记、视频）。卡片上有直接操作：选这个方向、确认脚本、改这张图（弹输入框）、选图排序后确认、生成视频。输入框随时可以发自由文本。智能体回复流式显示（SSE，`react-native-sse` 或同类纯 JS 实现）。有生成中的任务时每 3 秒拉 `/state` 刷新图片状态；
  - 笔记预览：仿小红书笔记的样子（图片轮播、标题、正文、#话题），一键复制文案、保存图片到相册（用 Expo Go 支持的库），视频可播放；
  - 设置：服务器地址（默认读 `EXPO_PUBLIC_API_BASE`，可在 App 内改，便于连本地或线上）、退出登录。
- **风格**：干净的白底、小红书红 `#FF2442` 作强调色、圆角卡片、中文文案自然口语。加载、空状态、出错都要有像样的提示，网络断了能重试。
- **开发用假服务**：在 `app/mock-server/` 用 Node 写一个按 `docs/设计.md` 第 4 节返回假数据的服务（含 SSE 和任务状态推进），图片用 `docs/spike/` 里的实测图，让 App 不依赖真实后端也能完整走一遍。
