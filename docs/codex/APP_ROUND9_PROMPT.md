# App 第九轮：片场感、点数、一键出片入口、离开再回来

## 目标

把 `docs/设计.md` **第 14 节**里属于 App 的部分做出来（**唯一契约，字段名照它来**）。服务端正在另一个 worktree 同步实现 14.1 / 14.2 / 14.4 的字段，你先按契约改 App 和假服务（`mock-server/`），让假服务也返回这些新字段，便于端到端测试。

按优先级：

1. **14.5 片场感**：全局换词（词汇表照抄，含无障碍标签和测试选择器）；新建页重做（大标题、「一键出片 / 沉浸编导」切换 + 说明 + 问号弹层、三张卡、"描述你的风格" + 12 个风格词条每次 8 个 + 换一批、底部一个开拍按钮带估价）；首页重做（深色影棚、灵感墙用 `assets/inspiration/studio-01..10.jpg`、进行中区、我的片场、拍一组新片）；`theme.ts` 加 `studio` 色板；首页 / 登录 / 引导 / 新建页用 studio，编导间与预览保持纸色；引导页三页文案照 14.5。
2. **14.1 点数**：用户可见处只出现"点"，不再出现 ¥ / 元 / 费用 / 花费 / 价格（`transparency.ts`、确认按钮、消息小字、设置、引导）；字段优先读 `*_points`，缺失时按 10 点 = 1 元从 `*_cny` 换算。
3. **14.2 一键出片**：新建页按模式发 `mode` 与 `style_tags`；"开拍"按钮显示 `GET /api/quotes/auto` 的估价；auto 项目的编导间显示步骤进度条与当前步骤（`state.auto`），不显示确认按钮，有"我来接手"调 `POST /api/projects/{id}/mode`；每步主动消息正常显示。
4. **14.4 离开再回来**：首页「进行中」区（`progress`）、5 s 刷新、回到前台刷新、"刚刚出好"条目；auto 完成走现有通知。

UI 要有 Chiccify 那种"片场"的质感（深底、玻璃面、细线、细字重大标题、字间距），但不要照抄它的文案；中文、口语、短。保持现有组件体系（`src/components/ui.tsx`、`theme.ts` token），不要新造第二套样式。
