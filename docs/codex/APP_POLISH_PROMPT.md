# /goal：App 第五轮——视觉与手感打磨（不加功能）

功能已经齐了，这一轮只做一件事：让 App 在 iPhone 上"好看、顺手、像上线产品"。面试官是互联网大厂出来的，会在意细节。不新增功能、不改接口、不改假服务的数据结构。约定仍是 `docs/设计.md`；设计语言延续现有（红 #FF2442 主色、米白背景、卡片圆角），不换风格，往"精致"方向收。

## 要做到的

- **节奏统一**：建立并全局使用一套间距（4/8/12/16/24/32）、圆角（12/16/20）、字号层级（标题/副标题/正文/辅助/角标）和颜色 token；消灭页面之间不一致的留白和字号。所有可点元素 ≥ 44pt 点击区。
- **加载与过渡**：列表、项目详情、笔记预览首屏用骨架屏代替转圈；图片用淡入；卡片、消息进入有轻微上滑淡入；页面切换、弹层、底部菜单有合理动效（用 reanimated，别卡）；长任务（出图/视频）的进度区做成有呼吸感的状态条，而不是一行文字。
- **按压与反馈**：按钮、卡片、缩略图有按压态（缩放/变色）；成功/失败提示统一成顶部或底部的轻提示组件，带图标，自动消失；危险操作（删除）配色和二次确认统一。
- **空态与错误态**：项目空态、无图片、断网、登录过期各有一套图标 + 一句话 + 一个动作，视觉统一。
- **对话工作台**：消息气泡、卡片、输入区的层次更清楚；长卡片（脚本、图片）内部分区有标题和分隔；底部输入区在键盘弹起时不遮挡最后一条消息；阶段进度条（01 选择方向 … 04 笔记就绪）做成可读的步骤指示，当前步高亮并带动画。
- **图片相关**：缩略图统一比例和圆角；查看器底栏、版本条、笔刷工具条的图标和间距精修；"还原 96"、"v2"、"AI生成"等角标样式统一成一套小标签组件。
- **笔记预览**：更像小红书的发布预览——封面大图、标题、正文分段、话题标签为胶囊、底部操作栏固定；成本和 AI 声明做成低调的信息行。
- **首页**：顶部主视觉和"新建品牌合作"按钮已经不错，项目卡片加封面/阶段/更新时间的层次，列表项之间的间距统一。
- **图标与启动**：检查 App 图标、启动页在真机上的观感（圆角、留白），必要时重做 `assets/icon.png`、`splash-icon.png`（简洁、品牌色）。
- **可访问性**：所有图标按钮有 accessibilityLabel；文字对比度达标；动态字体放大一档不崩。
- **安全区与刘海**：所有页面顶部/底部安全区正确，横屏不考虑。
