# /goal：App 第三轮——把"看图、改图、局部改"做成手机上顺手的交互

博主在手机上最常做的事是看图和改图：放大看袖口、纽扣、面料；圈出袖口说"放下来"；拿两版对比；在对话里指着某张图说事。现在 App 只有"点改一改 → 弹框打字"，太粗。新约定见 `docs/设计.md` 第 8 节（只增不改），服务端正在并行实现局部改、指令核对和引用。

## 成功标准（Claude 会复测）

- **C1 全屏查看器**：点任意生成图进入；左右滑切换；双指缩放 + 双击放大，缩放后能拖动；底部版本条（按 `parent_id` 链，v1/v2/…）；前后对比滑块（拖动看两版差异）；显示还原分、`edit_check` 结果和 AI 生成角标；关闭回到原位置。
- **C2 局部改**：查看器里进入圈选模式：手指涂抹（笔刷粗细可调、撤销、清空，半透明高亮显示涂过的地方），可切换框选；缩放状态下涂抹坐标也要正确换算成相对原图的 0–1 坐标（`contentFit` 留白、缩放、平移都考虑到）；快捷说法按场景给（袖口放下来 / 衬衫塞进裤腰 / 去掉吊牌 / 换个颜色 / 背景亮一点 / 自己输入）；提交发 `edit_image` 带 `mask_strokes` 或 `region`；生成中在版本条上显示占位，完成后自动切到前后对比。
- **C3 引用到对话**：长按图片或查看器里点"引用"，输入框上方出现缩略图（可删除），发送时带 `refs`；对话里用户消息显示被引用的缩略图，点开进查看器。
- **C4 长按菜单与反馈**：图片长按出菜单（局部改 / 整张改 / 引用到对话 / 对比版本 / 保存到相册），关键操作有触感反馈；`edit_check.passed=false` 时显示"可能没改到位：原因"和"再试一次 / 换个说法"。
- **C5 假服务与截图**：`mock-server` 支持 `region` / `mask_strokes`（假实现：在区域上做明显可见的处理）、`refs`、`edit_check`（包括一次"没改到位"）；无头流程截图新增：查看器、缩放、版本对比、涂抹中、局部改结果对比、引用发送、长按菜单、没改到位提示。
- **C6 质量**：手势和绘制只用 Expo Go 支持的库（如 react-native-gesture-handler、react-native-reanimated、react-native-svg）；坐标换算有单元测试（含留白、缩放、平移、横竖图）；`npm run verify`（Node 22）全部通过，iOS prebuild 仍成功。
