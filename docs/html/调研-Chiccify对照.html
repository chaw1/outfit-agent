Chiccify（即刻达人）竞品调研 — 对照「衣序」¶

调研时间：2026-10-21 凌晨。方法：搜索引擎（中英）+ 打开能打开的页面 + 直接拉取 musegate.tech 及四个子产品的前端 SPA 代码包，解出全部中文 UI 文案（最硬的一手证据）。Playwright 被另一会话占用，未能登录实操。

可信度标注：【官方】官网/产品代码里的文案；【媒体】访谈报道；【笔记】Gary 本地面试准备笔记（~/Downloads/面试/霖润/，来自早前登录产品的观察）；【推测】我的推断。

0. 结论（先看这里）¶

  1. Chiccify 是 MuseGate 旗下桌面 Web 子产品（chiccify.musegate.tech），面向博主/达人做小红书、抖音、Instagram 社媒图文；页面自己写着"桌面端体验优化，移动端功能可能受限"。没有 App、没有小程序——我们的手机 App 是差异化，不是劣势。
  2. 它的"Agent 对话创作"主干和我们几乎同构：上传服饰图+模特图 → 多组风格灵感图挑选 → 定主图 → 自动策划全套配图 + 文案 → 发布面板 → 本地助手扫码发小红书。另外有"一键出片"全自动模式（不做选择题，直接拿全套）。
  3. 它比我们强的地方：灵感图是多组可选的真图、主图确认后以主图为锚点出全套（人脸/风格一致性靠"锚点"而非口头承诺）、Agent 面板展示思考过程 / 使用能力 / 总耗时 / 生成花费 / 来源图、发布面板是完整的小红书发帖表单（标题、正文、合集、地点、原创声明、草稿箱）、模特库 + 专属模特训练 + 上链存证、十几种修图小工具（消除笔、局部重绘、换头、换背景、去皱、扩图、2 倍高清）、图生视频分镜（Seedance 2.5 / 可灵 / Veo）、缪斯点按张计费且提交前预估扣点、失败退点。
  4. 我们已有而它没公开的：手机端全链路；对话里自然语言圈选局部改 + 圈外像素不变 + 改后核对（它有涂抹局部重绘，但是工具页不是对话）；还原分质检 + 低分自动修；脚本版本历史/回滚；成本实时显示在笔记上；管理端（配额/分层/任务队列）；AI 生成角标与元数据；博主风格偏好进上下文。
  5. 今天最值得补的 5 点（详见第 5 节）：① 方向卡配灵感图并可"换一组"；② Agent 消息的过程透明（正在扫描服饰细节 / 使用了什么能力 / 耗时 / 花费）；③ 花钱动作前的"预估扣费 → 确认"气泡 + 失败自动退费记账；④ 发布面板向小红书发帖表单靠拢（标题字数提示、话题、原创/AI 声明勾选、草稿）；⑤ 一键出片"全自动模式"开关（不做选择题，直接到成稿）。

2. Chiccify 功能清单（全部来自 chiccify.musegate.tech 代码包文案，【官方】）¶

2.1 目标用户与入口¶

  • 博主/达人：按钮"创建小红书笔记 / 创作抖音 / 创建Instagram Post"；演示账号名"小红书达人_official / 时尚穿搭日记 / 美妆种草机"。
  • 入口："智能体"（对话）、"社媒策划"、"试穿"、"自定义模特"、"我的资产"、"历史对话"、"草稿箱"。
  • 素材三槽位：服饰图（必填）+ 模特图（必填）+ 参考图（选填）+ 文案（选填）；"模特只能从模特库选择"（Chiccify 模特 / 我的专属模特 / 收藏模特 / 外部模特 / 人台/假人模特图）；可从 MuseGate 服装库选货号。

2.2 两种创作模式（页面原文）¶

  • 沉浸编导："慢慢选，步步调"。① 选灵感：生成多组风格灵感图供挑选（有参考图则结合参考图发散）；② 定主图：选中一张后 AI 把服饰和模特融入生成主图；③ 收全套：确认主图后"以此为基调，自动策划并生成全套补充大片"。"参与度最高，掌控感最强，打磨时间相对较长"。
  • 一键出片："交给我们，全套图文笔记一次性极速直出""提交素材后可以去喝杯咖啡""0 操作成本，全自动盲盒惊喜体验"。参考图在此模式为必填。

2.3 Agent 对话的交互细节¶

  • 默认提示词模板：基于上传的服饰图和模特帮我策划一条发布在{平台}上的图文笔记；输入框"描述你想创建的社交内容..."；支持"我想要 xx 风格"解析。
  • 阶段进度语："正在扫描服饰细节..." → "正在搜寻美学灵感..." → "正在渲染风格预览..." → "眼光不错！让我来为你创作最完美的主图…正在将你的服饰和模特植入这套美学体系中" → "正在为你策划笔记的全部内容..." → "正在生成第 N 张图片..." → "撰写文案..."。
  • 消息卡片有 思考过程 / 使用能力 / 查看过程 / 总耗时 / 来源图 / 生成花费；"ChicImage 生图排队中"。
  • 素材补充环节：Agent 会要求"补充素材"，用户可"已补充素材并确认"或"跳过补充，继续生成"；"确认图片角色"（哪张是服饰、哪张是模特）。
  • 自由对话（free_chat）：WebSocket 实时推送（有 ack 超时、断线降级为历史浏览、会话被别的页面接管提示）；"上一条自由对话还在处理中"串行限制。
  • 推荐风格方向是场景化一句话，如"周日早晨去买咖啡，松弛又温暖的氛围""雨天在城市里散步，安静又有点电影感""假日旅行的机场穿搭"（10 条预置）。
  • 方案面板：整体创作方向、分镜解构（镜头列表，可添加/删除/恢复/重命名、"已达上限"）、帖子标题、帖子文案，"点击文字可编辑"、撤销/重做；候选图可替换槽位，主图是只读槽位；"重新生成""转为视频"。
  • 历史对话侧栏：置顶、重命名、删除、回收站、归档只读。

2.4 编辑与修图工具（工具页，非对话）¶

  • 消除笔、局部重绘（画笔涂抹 + 指令）、手部修复、换头、换背景、裁图（比例模板）、扩图、2 倍高清放大、衣服/羽绒服去皱（轻中重）、细节修补、服装换色/背景换色、服装改款、服装转平铺/转 3D、多件/双人/自由换衣、配饰（耳环/包袋/手表/项链）、模特捏脸（多角度）。
  • 文案工具矩阵：细节特写/平铺图/面料属性/无模特/模特图换脸或不换脸 × 保留原文案/无文案/应用新文案/AI 编辑文案/去除文案；"AI 编辑文案-局部改字"；"AI 文案识别"。

2.5 视频（共用 ChicVideo 能力）¶

  • 图生视频 5 秒 / 10 秒、首尾帧、添加音效、视频修脸、一键成片、视频模仿、视频拼装、视频抽帧；OOTD 分镜 / 种草视频分镜脚本 → 逐镜头编辑 → 生成；模板来自上传视频拆解（≤30 秒）；"15 秒以上模版仅支持 Seedance 2.5"，"可灵分镜总时长"限制；"内部账号暂不开放视频创作"。

2.6 发布与分发¶

  • 发布面板 = 小红书发帖表单：标题（"添加标题，获得更多点赞"）、正文（"写下你的故事…"）、选择平台、添加到合集、原创内容、添加地点/路线、允许合拍/复制、公开、存草稿、预览、下载全部到本地；草稿箱与覆盖提示。
  • 真正发布：需要安装"Chiccify 小红书发布助手"本地程序（下载解压、macOS 首次允许运行、扫码登录小红书 App），"当前本地发布仅支持小红书"；按钮里有"发布功能即将上线"字样，说明发布还在灰度。

2.7 生成质量承诺¶

  • 公开口号："高还原是生死线，高审美是入场券"（【媒体】）。产品里没有"还原分""相似度"之类量化指标；一致性靠"主图作为视觉锚点"、换脸/修脸（FaceFusion）、专属模特 LoRA（步数 4000、lr 2e-4、rank 32，【笔记】）。未公开任何人脸一致性数字。

2.8 定价与计费¶

  • 点数叫"缪斯点"，按张扣费；提交前"正在计算所需缪斯点…""价格已变化，本次未提交，请重新确认扣点"；"点击重新生成将扣除 N 缪斯点，是否继续？"；"Muse 点余额不足，请充值后重试""去充值"；失败批量退点（【笔记】）。
  • 代码里出现"300 Muse 点套餐""注册赠送""新手套餐权限""{{0}} 缪斯点/张""0.2 缪斯点""1200缪斯点"，以及 B 端套餐名"启航版 4999 元 / 基础版 19999 / 旗舰版 49999 / 至尊版 99999 / 黑金 VIP 包 19999"（支付宝/微信）。具体每张单价和 C 端套餐价格未公开，以上数字含义未证实。
  • 商业模式"先充值后消耗"，长期想做分润（【媒体】）。

2.9 合规¶

  • 下载三选一：官方水印（右下角）/ 商家水印方案（最多 5 个）/ 无水印（需确认"仅用于你有权使用的内容"，"应用级配置禁止去水印"可由后台关掉）。
  • 标签"AI生成"、"图片防盗用标识"、"缺少来源标识的图片"、下载时写回 EXIF；免责声明 / 用户服务协议 / 隐私政策；专属模特"自动上链存证""允许平台代理提交存证与维权"。
  • 未见显式"AI 内容声明"勾选项或对《标识办法》的说明。

2.10 资产与模特¶

  • 资产中心：文件夹、一二级标签、批量上传、自动打标、待确认、低质量库（【笔记】）；Chiccify 里"我的资产 / 服装库（年度/波段/系列/货号筛选）/ 平台素材分组 / 收藏"。
  • 专属模特：创建我的模特、训练中/审核中、置信链存证、AB 实验自动出图（【笔记】）。
  • 角色体系：客户 / 销售渠道商 / 运营 / 审核员 / 管理员 / 财务 / 演示账号 / 虚拟商家 — 分销商体系。

4. 技术栈线索（【官方】代码 / 【笔记】JD）¶

  • 前端 umi + React + Ant Design Pro，单 SPA，多子域名 SSO；接口 /service，阿里云 SAE；Agent 通道 WebSocket V2（ack、session、channel 降级、RecoveryManager 恢复历史消息）。
  • 后端 Java/Spring（用户、租户、点数、任务编排父子任务、分销）+ Python（ComfyUI、训练、打标）【笔记/推测】。
  • 模型：自研 Chic-Image；FaceFusion 换脸；FLUX LoRA 专属模特；视频 Seedance 2.5 / 可灵 / Veo / Vidu。

5. 今天最值得补的 5 点（18 小时、两个 Codex 并行）¶

按「面试官观感提升 ÷ 实现成本」排序：

  1. 方向卡"换一组"+ 灵感图可多选为参考（观感高 / 成本低）。方向卡已有 1 张预览图；加"换一组方向"按钮（重跑 direction 节点，旧的保留可回看）和"参考图"槽位（新建项目时可传 1 张博主喜欢的图，进方向与脚本 prompt）。这直接对应它的"① 选灵感"。
  2. Agent 消息的过程透明（观感高 / 成本低）。每条智能体消息下折叠一行"用了：看图 · 出方向 · 预览图 ×3 ｜ 耗时 14s ｜ 花费 ¥1.5"，数据来自已有 usage_ledger 和 jobs；阶段进度语改成 Chiccify 那种有人味的句子（"正在扫描服饰细节…"）。服务端只需在 message 上加 trace?: {tools, elapsed_ms, cost_cny}。
  3. 花钱前的"预估扣费 → 确认"气泡 + 失败自动退费（观感高 / 成本低）。确认脚本时显示"将生成 6 张，预计 ¥9.6，今日剩余预算 ¥40"；任务失败时 ledger 写负项并在消息里说"第 3 张失败，已退回 ¥1.6"。管理端已有预算，只差前台展示和退费记录。
  4. 发布面板向小红书表单靠拢 + 草稿（观感中高 / 成本中）。笔记页改成：标题（20 字计数）、正文、话题 chips、"原创 / AI 生成内容"两个勾选、"存草稿"（本地）、再接已有的"准备发布"。面试官一看就知道是对着小红书做的。
  5. "一键出片"开关（观感中 / 成本低）。新建项目时勾"全自动：不用我确认，直接出成稿"，状态机自动放行 direction→script→images→note，中途仍受预算拦截；对比它的"沉浸编导 vs 一键出片"两模式，正好演示我们状态机"确认门可配置"。

不建议今天碰：自动发布助手、专属模特训练、修图工具矩阵、资产中心、10 秒多模型视频。
