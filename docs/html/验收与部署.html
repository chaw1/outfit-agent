管理端¶

页面截图（桌面 1280 与手机 390）：admin-shots/，总览含最近 7 天趋势、模型费用占比与任务成功率。

和 API 同一容器：/admin（独立口令，ADMIN_TOKEN 为空时整体关闭）。总览、用量统计（按模型 / 用户 / 天，导出 CSV）、模型分层与每日配额（存库即时生效）、任务队列（重试 / 取消）、用户管理（禁用 / 层级）。花钱的动作在服务端按层级预算门禁，对话不受限。约定见 设计.md 第 9 节。

部署¶

单台阿里云 ECS，docker compose（api、worker × 2、postgres）+ 宿主机 nginx 终止 TLS。域名未在阿里云备案接入，域名 HTTPS 会被按 SNI 拦截，所以使用 Let's Encrypt 的 IP 证书（每天自动续期）。部署脚本：server/deploy/deploy-ecs.sh。模型密钥只放在服务器环境变量，仓库不落。
