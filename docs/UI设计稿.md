# 衣序 · UI 设计稿

这是「先设计、后实现」的评审与开发依据。[高保真设计板](design/index.html)按首次进入、开拍、编导、挑图发布、账号管理排列；每个手机画布为 390 × 844。数据、动作与范围遵循 [设计契约](设计.md) §1.1、§8、§10–§16，接口变化仍先回到契约。设计板展示规划中的完整产品，不代表所有页面已经在 App 落地。

## 1. 设计目标与原则

- **片场是暗的，编辑桌是亮的。** 灵感、登录、引导与开拍用 `studio`；编导间、笔记预览与账号表单用 `paper`。图片查看器保持深色，让衣服与细节先被看见。
- **一次只问一个问题。** 沉浸编导依次定方向、定脚本、挑图片、定视频。当前需要的动作贴着内容出现；一键出片只报告当前步骤，保留「我来接手」。
- **花钱前先说清。** 用户界面统一以点数表达；正式出图与视频分别确认。一键出片在开拍时说明完整预估和自动推进范围；换一组方向、改图和重试也显示预估。
- **错误要能恢复。** 保留输入、原图、版本链、已完成镜头与本地草稿。改图传输重试复用同一 attempt，普通写请求不自动重放；「再试一次」才建立新尝试；未改到位的新版本不自动入稿。
- **用户只看点数。** 主按钮显示本次预估，辅助文案显示今日可用点数；不足时明确恢复时间，不引入充值或订阅入口。

## 2. 信息架构

产品页面与内部字段分别命名：面向用户使用「我的片场」「这组片」「编导间」「出镜的人」；文档中的 `project`、`image`、`note` 等仅用于开发映射。没有手机号验证、支付、自动发布、社交互动或用户侧组件画廊。

```mermaid
flowchart TD
  First[首次启动：隐私提示] --> Guide[三屏引导]
  Guide --> Auth[登录 / 注册]
  Auth --> Code[注册后保存恢复码]
  Code --> Home[首页：灵感墙 / 进行中 / 我的片场]
  Auth --> Forgot[忘记密码：恢复码找回]
  Forgot --> Code
  Auth --> Legal[用户协议 / 隐私政策 / AI 内容免责声明]
  Home --> New[拍一组新片]
  New --> Room[编导间：方向 / 脚本 / 出图]
  Room --> Viewer[图片查看器：版本 / 对比 / 局部改]
  Viewer --> Select[挑图：采用 / 手动采用]
  Room --> Select
  Select --> Note[笔记预览：本地草稿 / 图片顺序 / 发布清单]
  Note --> Video[视频确认 / 生成 / 就绪]
  Video --> Publish[准备发布：复制 / 保存 / 系统分享]
  Note --> Publish
  Home --> Manage[我的片场：搜索 / 阶段 / 删除确认]
  Home --> Settings[设置]
  Settings --> Profile[我的形象：照片 / 身高体型 / 风格偏好 / 昵称]
  Settings --> Security[账号与安全]
  Security --> Password[修改密码]
  Security --> Recovery[重新生成恢复码]
  Security --> Delete[注销确认]
  Security --> Legal
  Settings --> About[关于：版本 / 服务地址 / 隐私说明]
  About --> Legal
```

| 分区 | 页面与主要出口 | 约束 |
|---|---|---|
| 首次进入 | 隐私提示 → 引导 1–3 → 登录 / 注册 → 恢复码 | 同意隐私提示后才进入引导；注册同意勾选独立记录；恢复码只展示一次 |
| 片场 | 首页、拍一组新片、我的片场 | 灵感图片可查看；进行中优先恢复；素材为衣服、出镜的人、参考图三张卡 |
| 编辑桌 | 编导间、图片查看器、挑图、笔记预览、视频 | 沉浸编导逐项确认；一键出片可接手；保留版本和检查结果 |
| 个人与账号 | 设置、我的形象、账号与安全、修改密码、恢复码、忘记密码、注销、关于、协议页 | 仅用户名与密码；注销为二次确认；旧服务不支持的新增入口隐藏 |

### 2.1 沉浸编导

```mermaid
flowchart TD
  A[拍一组新片：mode=guided] --> B[衣服必填 / 出镜的人与参考图选填]
  B --> C[开拍，先聊灵感]
  C --> D[编导间：2–3 个方向]
  D -->|换一组：先展示点数| D
  D -->|选择方向| E[脚本草稿：标题 / 封面 / 镜头 / 视频]
  E -->|继续聊或恢复历史脚本| E
  E --> F{确认脚本与点数}
  F -->|不足| R[保留脚本，明天 00:00 恢复]
  F -->|确认| G[先生成封面，再生成其余镜头]
  G --> H[查看原图与新版本 / 局部改]
  H --> I{改图核对通过？}
  I -->|是| J[最新通过版本可默认采用]
  I -->|否| K[未改到位：保留原版，可重试或仍然采用]
  K -->|显示原因，用户确认| L[手动采用]
  J --> M[挑图与排序 → approve_images]
  L --> M
  M --> N[笔记预览：本地编辑 / 保存草稿]
  N -->|note 阶段可重新选图| H
  N --> O{单独确认视频与点数}
  O -->|确认| P[视频生成 → 就绪]
  N --> Q[发布清单 → 准备发布]
  P --> Q
```

### 2.2 一键出片

```mermaid
flowchart TD
  A[mode=auto / style_tags] --> B[读取 quotes/auto：总预估与明细]
  B --> C[开拍，全自动 · 约 48 点]
  C --> D[推荐方向 → 脚本 → 封面与其余图片]
  D --> E[采用有效 v1 → 笔记 → 视频 → done]
  D --> F[步骤条 + 当前步骤 + 我来接手]
  E --> G[全套已出好 → 笔记预览 / 视频]
  F -->|接手| H[mode=guided：下一个确认点停下]
  H --> I[已在跑的任务继续]
  D -->|任一步失败或点数不足| J[停在当前阶段，转沉浸编导]
  J --> K[主动消息：停在哪 / 原因 / 下一步]
```

一键出片的自动推进授权集中在开拍按钮及其上方说明，进行中不显示方向、脚本或视频确认按钮。「我来接手」不会取消在跑的任务，也不承诺立即停机。

### 2.3 离开再回来与通知

```mermaid
flowchart TD
  A[生成已入队] --> B[离开编导间 / App 进入后台]
  B --> C[后台任务继续]
  C --> D[完成：本机通知 / 前台横幅]
  D -->|点通知| F[进入对应编导间并刷新状态]
  B -->|回到前台| E[立即刷新首页与这组片]
  E --> G[进行中：出图中 2/3 / 等你确认脚本 / 笔记已就绪]
  G -->|继续| F
  F --> H{有待确认动作？}
  H -->|有| I[定位方向 / 脚本 / 视频确认]
  H -->|无| J[恢复步骤进度或结果]
  E -->|离线| K[保留上次进度，提示连接后刷新]
```

首页有 `generating` 时每 5 秒刷新，进入编导间有 `active_jobs` 时每 3 秒读状态；显示已完成数量，不伪造百分比或预计剩余秒数。通知未授权不阻塞生成，仍可回首页继续。

### 2.4 账号闭环

```mermaid
flowchart TD
  A[隐私提示] -->|同意并继续| B[引导 → 登录 / 注册]
  A -->|暂不使用| A0[停留隐私提示，不进入引导]
  B -->|注册：勾选协议与隐私| C[注册成功：恢复码只返回一次]
  C -->|复制 + 我已保存| D[首页]
  B -->|忘记密码| E[用户名 + 恢复码 + 新密码]
  E -->|验证成功，旧登录失效| C
  D --> F[账号与安全]
  F --> G[当前密码 + 新密码 → 修改密码]
  G --> H[更新本机登录，其他旧登录失效]
  F --> I[输入当前密码 → 重新生成恢复码]
  I --> C2[保存新恢复码：复制 + 我已保存]
  C2 --> F
  F --> J[注销账号：说明影响 + 输入密码 + 再次确认]
  J --> K[清理全部项目与媒体，回登录：账号已注销]
  B --> L[协议页：用户协议 / 隐私政策 / AI 内容免责声明]
  F --> L
```

账号找回统一提示「账号或恢复码不正确，请核对后重试」，不分别透露账号是否存在。恢复成功和重新生成恢复码后，都要求保存新码；旧码失效。注销失败留在确认页，不清除本地输入之外的账号状态。

## 3. 视觉语言

### 3.1 双主题与色板

### 3.3 尺寸与图片

| 组 | Token 与值 | 规则 |
|---|---|---|
| 间距 | `space.xs / sm / md / lg / xl / xxl` = 4 / 8 / 12 / 16 / 24 / 32 | 对应 `--space-xs` 等；页面左右 24，卡内 16，卡间 12，分区间 24–32 |
| 圆角 | `radius.sm / md / lg` = 12 / 16 / 20 | 输入 12，按钮与卡片 16，图片容器与 Sheet 20；词条为胶囊 |
| 布局 | `layout.touch` = 44；`layout.maxWidth` = 520 | 手机画布 390 × 844；按钮高 52；所有图标、返回、词条与内联动作最小触控 44 |
| 图片 | `layout.thumbnailRatio` = 3/4 | 灵感、方向、挑图缩略图使用 3:4；完整查看器 `object-fit: contain`，不得裁掉原图 AI 标识；封面锚点明确标注 |
| 安全区 | 顶部 44，底部 24 | 底部固定主操作不盖住滚动内容；键盘弹出后内容仍可滚动 |

生成图右下角保留可见「AI生成」标识（素材已带原始标识），缩略图覆盖裁切时补一枚同文案角标；原图只显示原标识。查看器左上或图下承载「未改到位」，不遮衣服关键细节；发布预览与清单保留「AI 生成内容」声明及「手动采用」。灵感素材仅作成片示意，不当作用户本人照片或上传衣服原图。

### 3.4 动效

`motion.fast / normal / slow / pulse` = 160 / 240 / 360 / 1200ms：按下反馈、卡片进入、Sheet 出入、加载占位。主按钮按下缩至 .975；导航淡入并位移不超过 8px。生成进度来自真实任务数量；不确定阶段用文字和短进度条，不制造进度百分比。减少动态效果开启时取消位移、缩放与脉冲，保留即时状态更新。设计板为静态定格，主题切换仅 160ms；截图时关闭动画。

## 4. 页面设计

以下 35 节与设计板画布一一对应。配图是设计定格，按钮、选区与播放条用于评审布局；浏览器可滚动长内容，只有顶部主题预览可交互。每节列出空、加载、错误、成功、点数不足；不扣点的页面明确写出不适用，避免为了凑状态引入功能。旁注只摘录关键变体，完整处理以下表为准。

主题切换对照：[首页的 paper 预览](design/shots/theme-paper.png)、[编导间的 studio 预览](design/shots/theme-studio.png)。[浏览器检查记录](design/verification.json)与[复现方式](design/README.md)随稿交付。

### 4.1 隐私提示

**目标：** 在首次引导前说明资料用途，由用户决定是否继续。

**布局：** studio 主题；上方两张灵感成片拼贴；品牌引语、隐私提示与资料用途说明；协议文字入口；底部同意并继续与暂不使用。

![隐私提示 · 390 × 844 设计画布与旁注](design/shots/01-privacy.png)

| 状态 | 设计处理 |
|---|---|
| 空 | 首次启动尚未同意，停留此页。 |
| 加载 | 协议内容加载中，保留同意与退出的上下文。 |
| 错误 | 协议打开失败，提供重试，不自动记录同意。 |
| 成功 | 同意并继续后进入第一屏引导；暂不使用则不进入创作流程。 |
| 点数不足 | 此页不扣点，不显示点数门槛。 |

**文案口径：** 「隐私提示」；「先认识衣序，再开始创作。」；「查看《用户协议》和《隐私政策》」；「请仅上传有权使用的素材与肖像。」；「同意并继续」；「暂不使用」。

**契约映射：** §15.1–§15.2；同意发生在三屏引导之前。

### 4.2 引导·一件衣服

**目标：** 用完整成片示例解释从衣服到图文和视频的主链路。

**布局：** studio 主题；大幅灵感成片与深色渐变；示例编号及 AI 生成标识；底部展示标题、说明、三步指示与继续按钮。

![引导·一件衣服 · 390 × 844 设计画布与旁注](design/shots/02-guide-start.png)

| 状态 | 设计处理 |
|---|---|
| 空 | 首次进入第一屏，示例不代表用户本人照片。 |
| 加载 | 示例图未就绪时显示固定比例占位，标题与按钮保持可见。 |
| 错误 | 示例图加载失败时保留说明，可继续引导。 |
| 成功 | 继续进入两种模式说明。 |
| 点数不足 | 引导不扣点，不显示点数不足提示。 |

**文案口径：** 「一件衣服，一组大片」；「从衣服出发，把灵感、脚本和画面，慢慢整理成你的下一篇穿搭笔记。」；「AI生成」；「继续」。

**契约映射：** §1.1、§14.5；第一屏引导，示例仅用指定灵感成片。

### 4.3 引导·两种模式

**目标：** 让用户理解一键出片与沉浸编导的选择。

**布局：** studio 主题；大幅灵感成片、示例编号与 AI 标识；底部用一段话解释两种模式；第二步指示与继续按钮。

![引导·两种模式 · 390 × 844 设计画布与旁注](design/shots/03-guide-mode.png)

| 状态 | 设计处理 |
|---|---|
| 空 | 尚未选择创作模式，此页只解释，不创建这组片。 |
| 加载 | 静态内容直接呈现，无需等待远端结果。 |
| 错误 | 此静态页无请求错误；返回或继续均不改变创作资料。 |
| 成功 | 继续进入点数确认说明，实际模式在拍一组新片页选择。 |
| 点数不足 | 模式说明不扣点，不阻断阅读。 |

**文案口径：** 「一键出片，或者一步步来」；「交给我们，全套图文和视频一次出好，中途可以接手。想亲自打磨，就选沉浸编导。」；「继续」。

**契约映射：** §14.2、§14.5；第二屏引导，不在此页启动自动流程。

### 4.4 引导·点数确认

**目标：** 说明扣点授权、AI 标识与生成结果需要核对。

**布局：** studio 主题；大幅灵感成片和 AI 标识；底部说明两种模式的扣点授权及发布声明；第三步指示与进入衣序按钮。

![引导·点数确认 · 390 × 844 设计画布与旁注](design/shots/04-guide-points.png)

| 状态 | 设计处理 |

| **Page / Header** | 安全区、滚动和页面导航；`children`、`scroll?`；Header 的 `title`、`subtitle?`、`onBack?`、`right?` | `plain / scroll`；`back / root` | 正常、内容加载、标题更新；返回标签必填；有键盘时避免主动作遮挡字段；错误不卸载已填表单 | 最大内容宽 520；手机左右 24；Header 最小高 56，加系统安全区 |

### 5.1 组件组合与内容契约

主操作遵循同一组合：`Card / 内容 → 本次预估与今日可用点数 → Button`。预估读取 `pending_action.estimated_cost_points`；一键出片用 `quotes/auto.estimate_points` 与 `breakdown`；换一组用 `regenerate_estimate_points`；对话明细用 `trace.cost_points`，不到 0.1 点时显示「不到 0.1 点」。示例中的 48、18、15、5 点只说明构成，开发不得硬编码它们作为最新报价。

未改到位组合固定为 `ImageViewer + warning Badge + edit_check.reason + VersionBar`，恢复动作是「再试一次」「换个说法」「仍然采用」。新尝试生成新的 `attempt`，同一提交的网络重发复用 `attempt`；`reused=true` 时提示「这次和上次一样，没有重新生成」。质检不通过不改任务状态；用户确认采用后 `approve_images.accept_unverified` 记录图片，笔记与发布清单显示「手动采用」。

本稿选择 §11.4 允许的**本地覆盖后复制**：笔记标题、正文、标签和图片顺序的本地草稿用于发布，不增加保存笔记接口。草稿包含 `sourceFingerprint` 与 `dirty`；有冲突时先保留本地内容，再由用户选择。`note.image_ids` 的服务端修订仍通过 `approve_images`，本地编辑不假装已经写回服务端。

### 7.1 本轮验证与边界
