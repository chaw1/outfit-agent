# 功能清单

一页看全「衣序」做了什么。按用户走的顺序排，每条写在哪、怎么用。设计约定见 [设计.md](设计.md)，页面细节见 [UI设计稿.md](UI设计稿.md)，验收证据见 [验收与部署.md](验收与部署.md)。

## 1. 进入与账号

| 功能 | 在哪 | 说明 |
|---|---|---|
| 隐私提示 | 首次启动 | 同意后才进入；「暂不使用」停留在提示页 |
| 三屏引导 | 首次启动 | 介绍片场、编导间、出片 |
| 注册 / 登录 | 登录页 | 只用用户名和密码，注册需勾选协议与隐私 |
| 恢复码 | 注册后 | 只展示一次，复制并确认已保存；用于找回密码 |
| 忘记密码 | 登录页 | 用户名 + 恢复码 + 新密码，成功后旧登录失效 |
| 修改密码 / 重新生成恢复码 | 设置 → 账号与安全 | 需输入当前密码 |
| 注销账号 | 设置 → 账号与安全 | 说明影响 → 输密码 → 二次确认；清理全部项目与媒体 |
| 协议页 | 登录页、设置 | 用户协议、隐私政策、AI 内容免责声明 |

## 2. 首页：我的片场

| 功能 | 在哪 | 说明 |
|---|---|---|
| 灵感墙 | 首页 | 十种风格成片；点开看大图，「按这个风格拍一组」直接进新建页并带入风格与氛围描述 |
| 进行中 | 首页 | 正在出图 / 等你确认的项目优先露出，带已完成数量 |
| 我的片场 | 首页 | 项目列表：搜索、按阶段筛选（只列出现过的阶段，带数量）、长按删除（二次确认） |
| 素材库入口 | 首页 | 见第 8 节 |

## 3. 拍一组新片

| 功能 | 在哪 | 说明 |
|---|---|---|
| 两种模式 | 新建页顶部 | 沉浸编导（逐项确认）/ 一键出片（全自动，可接手）；带说明弹层 |
| 衣服 | 新建页 | 必填，相册多选上传，或「从我的衣服里选」（素材库） |
| 出镜的人 | 新建页 | 选填；默认用「我的形象」里的照片，可换、可上传 |
| 参考图 | 新建页 | 选填；只作氛围参考，不进成片 |
| 这次想拍什么 | 新建页 | 自由描述；风格标签多选，可换一批 |
| 一键出片预估 | 新建页 | 开拍前显示总点数与明细 |
| 品牌 / 项目名 | 新建页 | 选填，留空自动命名 |

## 4. 编导间：沉浸编导

| 阶段 | 功能 | 说明 |
|---|---|---|
| 方向 | 2–3 个穿搭方向 | 每个方向有预览图与搭配说明；先选中、再点确认，有提示 |
| 方向 | 换一组 | 先显示点数再重出；自由对话可提偏好（「搭配再简单一点」） |
| 脚本 | 脚本草稿 | 选定方向后立即写出：标题灵感、封面计划、分镜（场景 / 动作 / 镜头 / 搭配 / 文案）、短片灵感 |
| 脚本 | 改脚本 | 对话改任意内容（「把挎包换成双肩书包」）；每一镜有「换个场景 / 换个动作 / 换搭配 / 删掉这一镜 / 自己说」 |
| 脚本 | 历史版本 | 任意一版可回看、可恢复（时间旅行） |
| 脚本 | 确认出图 | 显示点数后确认；先出封面，再出其余镜头 |
| 出图 | 还原核对 | 每张图自动核对衣服还原度与人像一致性，给分与差异说明 |
| 出图 | 主动消息 | 出图完成后智能体主动汇报结果 |
| 出图 | 改图 | 对话改一版，或在查看器里圈选局部改（见第 6 节） |
| 出图 | 换一种氛围 / 整体调整 | 自由对话 |
| 挑图 | 采用与排序 | 勾选入稿图并排序；核对未通过的版本不默认入稿，可手动采用 |
| 笔记 | 写笔记 | 用选中图生成标题、正文、标签；对话可改（短一点、换标题、换标签） |
| 短片 | 确认与生成 | 单独确认点数；选首帧；就绪后在对话里点开播放 |
| 全程 | 快捷话术 | 输入框上方按阶段给三句常用话，不花钱 |
| 全程 | 过程透明 | 每条回复下可展开：用了哪个工具、耗时、点数、处理分步 |
| 全程 | 花钱门禁 | 所有花钱动作都要独立确认；重复确认不重复花钱；服务重启后续跑 |
| 全程 | 引用图片对话 | 引用某张图只讨论不改图；长按消息复制、换个说法 |
| 全程 | 越阶段保护 | 跨阶段请求被礼貌拒绝并说明当前该做什么 |

## 5. 一键出片

| 功能 | 说明 |
|---|---|
| 全自动 | 推荐方向 → 脚本 → 封面与其余图 → 采用 → 笔记 → 短片，一次授权 |
| 步骤条 | 六步进度与当前步骤 |
| 我来接手 | 任何时候切回沉浸编导，在下一个确认点停下；在跑的任务继续 |
| 失败兜底 | 任一步失败或点数不足，停在当前阶段并主动说明原因与下一步 |
| 收尾卡 | 跑完后在进度条下汇总：出了几张、入稿几张、笔记标题、短片状态；一键「看笔记并发布」或「再拍一组」 |

## 6. 图片查看器与局部改

| 功能 | 说明 |
|---|---|
| 查看 | 原图与各版本切换、左右对比、缩放 |
| 局部改 | 在图上涂抹要改的区域，写一句要求；只改涂抹区 |
| 核对结果 | 改图后再次核对；未改到位会说明原因，保留原版，可重试或仍采用 |
| 保存 / 分享 | 保存到相册、系统分享 |
| 存为模特 | 把满意的成片存进「我的模特」，下次出镜用 |

## 7. 笔记预览与发布

| 功能 | 说明 |
|---|---|
| 笔记预览 | 标题、正文、标签、图片顺序；本地可编辑、保存草稿 |
| 发布清单 | AI 内容声明提醒、图片与文案检查 |
| 准备发布 | 复制文案、保存全部图片与短片、系统分享面板；平台发帖由系统分享接手 |
| 重新选图 | 笔记阶段可回去换图 |

## 8. 素材库

| 功能 | 说明 |
|---|---|
| 我的模特 | 上传的本人照片与存为模特的成片 |
| 我的衣服 | 上传过的衣服；新建时可直接选用 |
| 我的成片 / 我的短片 | 所有项目的产出；点开预览、回到这组片 |

## 9. 我的形象与设置

| 功能 | 说明 |
|---|---|
| 我的形象 | 本人照片、身高体型、风格偏好、昵称；出图时自动参考 |
| 点数 | 用户侧只显示点数（10 点 = 1 元），每日额度不足时保留进度次日恢复 |
| 关于 | 版本、服务地址、隐私说明 |

## 10. 离开再回来

| 功能 | 说明 |
|---|---|
| 后台继续 | 生成任务在服务端排队执行，App 退后台不影响 |
| 通知 | 完成后本机通知 / 前台横幅，点开直达编导间 |
| 回前台刷新 | 首页与编导间自动刷新；进行中显示已完成数量 |
| 断线 | 保留上次进度，提示连接后刷新 |

## 11. 服务端

| 能力 | 说明 |
|---|---|
| 智能体 | LangGraph 状态图，7 个阶段，Postgres checkpoint 按项目持久化 |
| 阶段内 ReAct | 模型从当前阶段允许的工具里选，代码只管放行和花钱门禁 |
| 任务队列 | Postgres 队列，Worker × 2，SKIP LOCKED 领任务，失败重试 |
| 模型 | 对话 DeepSeek、看图 qwen3-vl-plus、出图豆包 Seedream 5.0 pro（备 wan2.7）、视频 wan2.6-i2v；管理端可切 |
| 出图质量 | 3:4 竖版、封面锚点保持人像一致、吊牌与包装自动去除、AI 标识 |
| 还原核对 | 每张图看图模型打分；改图二次核对 |
| 媒体 | 签名链接、按需出 JPEG 预览（360 / 720 / 1080） |
| 账本 | 按项目与用户记点数与元；每层每日预算 |
| 合规 | 隐私同意记录、AI 内容声明、注销清理 |

## 12. 管理端（`/admin`）

| 页面 | 说明 |
|---|---|
| 总览 | 用户数、项目数、调用与费用、阶段分布、任务状态、7 天趋势 |
| 用量统计 | 按模型 / 用户 / 天，可筛选、导出 CSV |
| 模型与配额 | 四种能力各用哪个模型；用户分层与每日预算；改了即时生效 |
| 任务队列 | 列表、失败重试、排队取消 |
| 用户管理 | 禁用 / 启用、改层级 |
